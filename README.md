# BABEL

A daily, gamified language game for polyglots. Type the most natural way to say
something; rarer, more native answers climb higher up the Tower.

- `docs/polyglot-game-design.md`: core game design (rounds, tiers, grading, modes)
- `docs/story-and-world.md`: story, characters, world and art direction
- `docs/gamification.md`: progression, rewards, social systems and build order
- `research/krillion/`: teardown of Krillion (the inspiration) plus a style demo,
  `look-demo.html`, and starter design tokens
