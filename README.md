# Language RPG (title TBD)

A language-learning RPG for polyglots. A rogue translation AI is wiping out the
shared language worldwide; travel country by country, learn to live in each
language, and fight culture-rooted bosses with spells made of what you can say.

- `docs/polyglot-game-design.md`: daily round, rarity tiers and grading (v1; tower mode)
- `docs/story-and-world.md`: campaign per country, Language Tower, Masters, characters
- `docs/gamification.md`: spells, boss battles, coins/shops, progression, build order
- `research/krillion/`: teardown of Krillion (the inspiration) plus a style demo,
  `look-demo.html`, and starter design tokens
